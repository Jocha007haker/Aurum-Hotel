# Aurum Hotel — Website

Sitio web desarrollado para un hotel boutique ficticio, creado **desde cero como parte de mi portafolio de desarrollo web**.

## 📌 Sobre el proyecto

Aurum Hotel es una página web diseñada para representar la presencia digital de un hotel boutique enfocado en una experiencia de lujo, elegancia y comodidad.

El proyecto fue desarrollado desde cero, trabajando una identidad visual orientada al sector hotelero y una interfaz diseñada para presentar el concepto, los espacios y la experiencia del hotel.

## 🛠️ Tecnologías utilizadas

* HTML5
* CSS3

## ✨ Características

* Diseño elegante y moderno
* Interfaz orientada al sector hotelero
* Presentación visual de las instalaciones y servicios
* Estructura web organizada
* Diseño adaptable a diferentes tamaños de pantalla
* Desarrollo realizado desde cero
